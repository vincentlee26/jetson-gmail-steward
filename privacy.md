# Privacy Policy – Jetson Gmail Steward

Last updated: 2026-11-22

This application is a personal tool used only by its developer for his own
Google account. It is not distributed to other users.

**Data accessed.** With the developer's consent, the app reads Gmail message
metadata and message content, and can add labels and move messages to Trash.
It never sends email and never permanently deletes email.

**How data is used.** Data is processed only on a device owned by the developer
(a local server on a home network), including by a locally hosted language
model. Email content is not sent to any third party or external AI service.

**Storage and sharing.** Email content is not stored beyond temporary
processing. Only message IDs and action logs are kept locally for undo.
No data is shared, sold, or transferred to anyone.

**Revoking access.** Access can be removed at any time at
https://myaccount.google.com/permissions
